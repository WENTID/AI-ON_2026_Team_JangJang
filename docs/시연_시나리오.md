# 시연 시나리오: "URL은 안전, 맥락으로 잡는다"

일반 URL 검사기는 주소와 페이지만 봅니다. 우리 서비스는 **QR이 붙어 있던 안내문의 목적**과 **실제 접속한 페이지의 목적**을 AI로 비교합니다.
이 차이를 보여 주는 시연용 사례입니다. 실제 피싱 주소는 쓰지 않습니다.

## 준비물
| 파일 | 내용 |
|---|---|
| `demo_site/*.html` | 가짜 페이지 4개. 서버 주소 `/demo-site/<이름>`으로 열림. 폼 전송 없음, 검색 노출 차단(noindex), 하단에 "시연용" 표시 |
| `demo/case1~5_*.png` | 안내문 포스터(QR 포함). 화면에 띄우거나 인쇄해서 휴대폰으로 찍음 |
| `scripts/demo_cases.py` | 포스터 만들기(`make`), 리허설(`check`) |

배포 주소가 정해지면 포스터를 다시 만듭니다. (QR에 배포 주소가 들어가야 함)
```powershell
.\.venv\Scripts\python scripts\demo_cases.py make --base https://<Render 주소>
.\.venv\Scripts\python scripts\demo_cases.py check          # 배포 서버로 5개 사례 리허설
```

## 사례
| # | 포스터 | QR을 찍으면 가는 페이지 | URL만 검사 | 안내문과 비교 |
|---|---|---|---|---|
| 1 | 공영주차장 요금 정산 | 경품 이벤트 응모 (이름·휴대폰·주소) | 정황 미약 5점 | **피싱 경고 45점** |
| 2 | 식당 테이블 주문 | 주식 정보 오픈채팅방 입장 | 정황 미약 5점 | **피싱 경고 45점** |
| 3 | 택배 무인보관함 | 쇼핑 회원가입 (이름·생년월일·휴대폰) | 정황 미약 5점 | **피싱 경고 45점** |
| 4 | (대조군) 공영주차장 요금 정산 | 주차요금 정산 페이지 | 정황 미약 5점 | 정황 미약 5점 (목적 일치) |
| 5 | 공영주차장 + **QR 위 스티커** | 경품 이벤트 응모 | 정황 미약 5점 | **피싱 위험 80점** (불일치 + 스티커) |

> **사례 6 후보 (11/22 로컬 확인, 포스터 미제작)**: 주차요금 안내문(기본 30분 1,000원) → 같은 정산 페이지인데 요금만 5,000원. 1차 목적 비교는 '일치'(정황 미약 5점)지만 **AI 교차 분석이 안내문과 페이지의 요금 차이를 근거 문장과 함께 찾아냄** → "규칙·1차가 통과시킨 것을 2차 AI가 잡는" 시연. 포스터 제작에는 Pillow(requirements-dev.txt) 필요
> 점수는 2026-11-20 로컬 리허설(`check --local`) 결과. 5점 = 무료 호스팅 주소(+10) − 정상 인증서(−5).
> 가짜 페이지는 비밀번호·카드 등 민감 입력란이 없고 브랜드 사칭도 없어, URL·페이지 검사만으로는 잡을 근거가 없다.

## 진행 순서 (약 3분)
1. **문제 제기** — "주차장 QR 위에 누가 스티커를 덧붙였다면? 주소 자체는 평범한 이벤트 페이지라 URL 검사기는 통과시킵니다."
2. **사례 1 (링크만)** — 휴대폰 앱의 "다른 방법으로 검사 → 링크 직접 입력"에 사례 1 주소 입력 → **정황 미약**
   - "주소·인증서·페이지 어디에도 피싱 근거가 없습니다. 기존 방식의 한계입니다."
3. **사례 1 (카메라로 포스터 촬영)** → **피싱 경고**
   - 결과 화면 "QR 목적 비교": 안내문 목적 *주차요금 결제* vs 페이지 목적 *경품 이벤트 응모*, 불일치 확률 100%
   - "Gemini가 사진 속 안내문을 읽고, Jev가 두 목적이 맞는지 확률로 판정합니다."
4. **사례 4 (대조군)** → 목적 일치, 그대로 정황 미약
   - "맞는 페이지는 괜히 막지 않습니다. 오탐을 줄이는 것도 중요합니다."
5. **사례 5 (스티커)** → **피싱 위험**
   - "덧붙인 스티커까지 알아보고, 스티커 + 목적 불일치 조합이면 위험으로 올립니다."
6. (시간 있으면) 사례 2·3 — 투자 리딩방, 개인정보 수집형 회원가입도 같은 방식으로 잡힘

## 주의
- Render 무료 서버는 15분 동안 접속이 없으면 잠듦 → **시연 5분 전에 한 번 접속해 깨우기**
- 카메라는 https 주소에서만 켜짐 (배포 주소 사용)
- 화면 밝기·반사로 QR이 안 읽히면 포스터를 인쇄해서 찍기. 업로드(사진 올리기)로도 같은 결과
- AI 응답이 실패하면 "QR 목적 비교: 확인 불가"로 나옴 → 리허설(`check`)로 미리 확인. 같은 사진·페이지는 캐시돼 다시 호출하지 않음
