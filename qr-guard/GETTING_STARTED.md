# 처음 실행하는 사람을 위한 가이드 (VS Code, 윈도우 기준)

이 문서만 순서대로 따라 하면 데모 화면을 띄울 수 있습니다. 약 15분 걸립니다.
더 자세한 기능 설명(평가 스크립트, 시나리오 추가 등)은 [USAGE.md](USAGE.md)를 보세요.

---

## 0단계. 프로그램 설치 (처음 한 번만)

| 프로그램 | 받는 곳 | 주의할 점 |
| --- | --- | --- |
| **Python 3.11** | https://www.python.org/downloads/ | 3.13 이상은 쓰지 마세요 (opencv 설치 오류). 설치 첫 화면에서 **"Add python.exe to PATH" 체크** |
| **Git** | https://git-scm.com/download/win | 설치 옵션은 전부 기본값으로 두면 됩니다 |
| **VS Code** | https://code.visualstudio.com/ | 설치 후 왼쪽 확장(Extensions) 탭에서 **"Python"**(Microsoft) 확장 설치 |

설치가 끝나면 **VS Code를 껐다 켜세요.** 그래야 새로 설치한 프로그램을 인식합니다.

---

## 1단계. 코드 받기

1. VS Code를 열고 `Ctrl+Shift+P`를 누른 뒤 **`Git: Clone`**을 입력합니다.
2. 이 저장소의 GitHub 주소를 붙여넣습니다. GitHub 페이지의 초록색 **`<> Code`** 버튼을 누르면 주소가 나옵니다.
3. 저장할 폴더를 고르고, "열기(Open)"를 누릅니다.

> 터미널에 익숙하다면 `git clone <주소>`로 받아도 됩니다.

---

## 2단계. 설치 (처음 한 번만)

VS Code에서 터미널을 엽니다. 메뉴 `터미널 → 새 터미널`을 누르거나 `` Ctrl+` ``를 누르세요.
아래 명령을 **한 줄씩** 붙여넣고 Enter를 누릅니다.

```powershell
py -3.11 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
copy .env.example .env
```

- 첫 줄은 이 프로젝트 전용 Python 환경(`.venv` 폴더)을 만듭니다.
- 둘째 줄은 필요한 라이브러리를 설치합니다. **1~3분** 걸리고, 글자가 많이 나오는 게 정상입니다.
- 셋째 줄은 설정 파일 `.env`를 만듭니다.

VS Code 오른쪽 아래에 "가상환경을 선택할까요?" 같은 알림이 뜨면 **Yes**를 누르세요.

### API 키 넣기 (선택)

왼쪽 파일 목록에서 `.env` 파일을 열고, `ANTHROPIC_API_KEY=` 뒤에 키를 붙여넣고 저장합니다.

```
ANTHROPIC_API_KEY=sk-ant-여기에키
```

- 키는 https://console.anthropic.com 에서 **각자** 발급합니다. 쓴 만큼 요금이 나옵니다.
- **키가 없어도 화면은 뜹니다.** 다만 메인 AI 판정은 "판단 보류"로만 나옵니다.
- ⚠ `.env` 파일은 절대 GitHub에 올리지 마세요. 키가 유출됩니다. 자동으로 제외되도록 설정되어 있으니 파일을 지우거나 이름만 바꾸지 마세요.

## 3단계. 실행 (할 때마다)

**서버 두 개**를 켜야 해서 터미널이 두 개 필요합니다.

| 터미널 | 무엇 | 왜 필요한가 |
| --- | --- | --- |
| 1 | 가짜 피싱 페이지 서버 | 진짜 피싱 사이트 대신 쓰는 테스트 페이지를 내 컴퓨터에서 띄웁니다 |
| 2 | 데모 화면 | QR을 올리고 판정 결과를 보는 웹 화면입니다 |

### 터미널 1

```powershell
.venv\Scripts\python mock_site\server.py
```
`가짜 테스트 페이지 서버: http://127.0.0.1:5001`이 나오면 성공입니다. **이 터미널은 그대로 켜 두세요.** 멈춘 것처럼 보이는 게 정상입니다.

### 터미널 2

터미널 패널 오른쪽 위의 **`+`** 버튼을 눌러 새 터미널을 엽니다.

```powershell
.venv\Scripts\streamlit run app.py
```

- 처음 실행하면 `Email:`이라고 묻고 멈춥니다. **그냥 Enter**를 누르세요.
- 브라우저가 자동으로 열립니다. 안 열리면 http://localhost:8501 에 직접 들어가세요.

### 끄기

각 터미널을 클릭한 뒤 `Ctrl+C`를 누릅니다.

## 4단계. 써 보기

1. 화면 맨 위 **"테스트 시나리오 불러오기"**에서 `P1`을 고릅니다.
2. **검사하기**를 누릅니다.
3. "URL만 검사"한 결과는 **안전**인데, 우리 판정은 **위험**으로 나오면 성공입니다.

QR 이미지로 해 보려면, 시나리오를 먼저 고른 다음 "QR 이미지 업로드" 탭에 `data\qr_samples\P1.png`를 올리세요.

> ❗ 시나리오를 **고르지 않고** 아무 주소나 넣으면 "서버에 연결할 수 없습니다"가 뜹니다.
> 시나리오 속 주소들은 실제로 없는 가상 주소라서, 시나리오를 골라야 가짜 서버로 연결됩니다.

## 안 될 때

| 증상 | 해결 |
| --- | --- |
| `py`는 인식되지 않는 명령이라고 나옴 | Python 설치 시 PATH 체크를 빠뜨림. Python을 재설치하고 VS Code 재시작 |
| `No suitable Python runtime found` | Python 3.11이 없음. 0단계에서 3.11 설치 (`py -0`로 설치된 버전 확인) |
| `pip install` 중 opencv 오류 | Python 3.13 이상으로 만든 환경. `.venv` 폴더를 지우고 2단계를 3.11로 다시 실행 |
| 브라우저에서 `localhost:8501`이 안 열림 | 터미널 2에 `Email:`이 떠 있는지 확인하고 Enter |
| "서버에 연결할 수 없습니다" | 시나리오를 골랐는지, 터미널 1이 켜져 있는지 확인 |
| 판정이 전부 "판단 보류" | API 키가 없음. `.env`에 키를 넣고 터미널 2를 껐다 다시 실행 |
| "API 키가 올바르지 않습니다" | `.env`의 키 앞뒤에 공백이나 따옴표가 없는지 확인 |
| "스크립트를 실행할 수 없습니다" | `activate`를 쓰지 말고 이 문서처럼 `.venv\Scripts\python ...` 형태로 실행 |

맥을 쓴다면 `.venv\Scripts\python` 대신 `.venv/bin/python`, `copy` 대신 `cp`, `py -3.11` 대신 `python3.11`을 쓰세요.
