# 2차 멘토링 정리 (2026-11-04)

> 본인 메모 + 팀원 정리를 합쳐 중복을 없애고 주제별로 재정리함.

## 핵심 요약
1. **판정 기준**: 큐싱 예방 수칙을 최상위 기준으로, 카테고리를 대분류(예방 수칙)·소분류(점수 기준)로 위계화하고 검사도 그 순서대로 진행
2. **AI 일관성**: 같은 주소에 다른 결과가 나오지 않도록 검사 규칙은 프로그램이 정적으로 정의, AI는 정해진 질의에만 답함(하네스)
3. **AI 변경**: Gemini → **Jev AI**, 용도는 QR 안내문 목적 ↔ 실제 페이지 목적 **일치/불일치 판별 하나** (이미지 문구는 **OCR 사용 확정** → 11/20부터 별도 OCR 도구 대신 Gemini 멀티모달이 읽음)
4. **주제 확장**: 피싱 분석기 → **QR 분석기** (QR 목적별 분류 + 범죄유형별 결과)
5. **UX**: 카메라 첫 화면 → 바로 결과 → 결과는 위험도만, 근거는 상세보기로
6. **플랫폼**: 웹 → 앱 방향 (난이도 고려 시 기존 웹 코드를 살린 웹앱도 가능)

---

## 1. 판정 구조·카테고리 개편

### 문제
- AI 응답에 변동성이 있어 **같은 주소가 다른 분석 결과**를 얻는 일이 생김
- 검사 규칙·AI 질의에 중복이 많아 프로세스가 무거움

### 결정
- **큐싱 예방 수칙을 판정의 첫 번째(최상위) 기준**으로 삼는다. 직접 만든 점수 규칙은 그 아래 단계.
- **카테고리 위계(하네스)**
  - 대분류: 큐싱 예방 수칙 (보안·피싱 등)
  - 소분류: 기존 점수 기준
  - 검사 워크플로우도 이 분류 순서대로 진행
- **검사 규칙은 AI가 자체 판단하지 않는다.** 프로그램에 정적으로 정의된 항목만 AI에 질의 → 결과 일관성 확보
- AI 질의·검사 규칙 중 **중복 제거**, 프로세스 경량화

## 2. AI 활용

- AI API: **Gemini → Jev AI** (TypeSafe AI의 판단 전용 모델)
- 용도: **맥락 판별만** — QR 안내문의 목적과 실제 접속 페이지의 목적이 일치하는지 참/거짓
  - 참/거짓만 얻으면 되므로 출력 비용·처리 속도 면에서 Jev AI가 유리
- 이미지 처리: Jev AI는 화면 구성·사진 속 문구를 직접 못 읽음
  - **결정: 무료 OCR로 사진 속 문구를 텍스트화해서 Jev에 전달** (OCR 사용 확정 → 11/20부터 Gemini 멀티모달이 대신함)
- 비전공자용 **AI 근거 해설은 지금 불필요**(선택 사항). 대신 IT 용어는 정의를 따로 적어 두거나 나무위키 등 외부 정의 링크로 대체

## 3. 비용·실행 환경

- 대회용으로는 **로컬 구동으로 충분** — API 대신 Claude Code 로컬 구동으로 바꾸면 비용 해결 + 성능 향상
- API를 바꿔도 코드 구조는 같으므로:
  - 개발 기간엔 무료 모델로 테스트 → 시연 때만 유료 모델로 교체, 또는
  - 고도화 계획 설명에서 대체 방식으로 언급

## 4. 주제 확장: 피싱 분석기 → QR 분석기

- **QR의 의도·목적을 먼저 분류** (결제 / 웹사이트 이동 등)하고 그에 맞춰 검사 항목 분류
- 피싱이 아닐 때 위험 요소를 단순 나열하던 방식 폐기 → **계층형 결과**
  - 대메뉴: 범죄 유형 (일반인도 아는 대표 용어, 예: 피싱)
  - → 범죄별 검사 항목 카테고리
  - → 세부 검사 항목
- 백신 프로그램 결과 로그처럼: 처음엔 **위험도만**, 카테고리를 타고 들어가면 세부 사유
- 결과 화면의 **중복 용어·표현 제거** (같은 의미 표현이 너무 많아 난잡함)
- 선택 사항: 전체 검사 항목을 나열하고 탐지 항목만 체크 vs 탐지된 항목만 표시

## 5. UX·플랫폼

- 사용자는 대부분 **휴대폰 카메라로 바로 찍는 방식**을 선호 → 앱 기준으로 UI·기능 재설계
  - 앱은 난이도 상승 → **기존 웹 코드를 살린 웹앱(PWA 등) 전환**도 가능
- 화면 흐름
  - 첫 화면 = 바로 카메라 / 업로드·URL 입력은 보조 메뉴
  - 찍으면 중간 과정 없이 바로 결과
  - 결과 첫 화면: **판정 + 해당 예방 수칙 한 줄 + 행동 안내**
  - 상세보기(원하는 사람만): 전체 근거, 점수, URL, AI가 읽은 안내문, 맥락 비교 결과

## 6. 발표·시연·마케팅

- 실제 피싱 주소: **살짝 변형해서 자료에만 첨부**, 시연은 가짜 주소로 하며 **안전상의 이유임을 강조**
- 마케팅 아이디어: 최종 발표 기간에 기존 교내 홍보물 QR을 대체 배포하고 장난 문구로 연결 (괜찮은 아이디어로 평가)
